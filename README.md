# MI++ / MIplusplus / Mipp

---
MI++ is an addon for [Modern Industrialization](https://modrinth.com/mod/modern-industrialization) that adds ore vein generation, building blocks ~~and more~~.

## Features
- Electric Prospector: a tool capable of searching for surrounding ore veins
- Advanced Ore Vein generation configurable through datapacks
- Electric Chunk Loaders
